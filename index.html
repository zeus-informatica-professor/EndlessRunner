Como estudar com o projeto

1. Observe

Abra a página e identifique o que foi acrescentado em relação à etapa anterior.

2. Investigue

Localize no HTML, CSS ou JavaScript o trecho responsável pelo comportamento.

3. Experimente

Modifique um valor por vez, execute novamente e registre o que mudou.

Organização do código

O projeto separa estrutura, aparência e comportamento. As páginas usam HTML, o arquivo css/style.css concentra os estilos e os arquivos em js/ cuidam da interação. Os eventos são registrados com addEventListener().
