Sobre o projeto

Este portal acompanha a construção progressiva de um jogo Endless Runner para apoiar o estudo de desenvolvimento web.

Objetivo pedagógico

Demonstrar como HTML, CSS e JavaScript trabalham em conjunto, permitindo que o estudante observe uma aplicação em evolução e investigue o papel de cada recurso.

O código privilegia separação de responsabilidades, eventos registrados com addEventListener(), criação dinâmica de elementos e animação com requestAnimationFrame().
