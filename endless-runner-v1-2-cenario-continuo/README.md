# Endless Runner — v1.2 — Evolução do Cenário

Sequência didática:
01 Céu
02 Cenário
03 Ambiente
04 Personagem
05 Chão
06 Geração aleatória e contínua
07 Movimento contínuo

A etapa 06 resolve o ponto fundamental: os elementos não são mais definidos manualmente no HTML. O JavaScript cria árvores dinamicamente, escolhe posições/intervalos aleatórios e remove elementos que saem da área de jogo.

A etapa 07 reúne criação + movimento + remoção para produzir um cenário contínuo.

Abra `01-ceu.html` e avance pelo menu.
